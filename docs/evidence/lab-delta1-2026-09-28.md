## Scope and interpretation

The twelve primary scenarios cover pipeline, fanout, signal, human approval, Gate
approval, Gate errors, late Gate decision, continuation, cancellation, run timeout,
approval expiry, and activity retry. Each runs beside a second workflow on the same
queue with distinct effect values. Three worker identities share the queue. Gate
pending, HTTP-503 errors and timeout errors must recover to approval; an approval
returned after its deadline must expire instead. A timeout/crash before a Gate poll
can expire some late-decision cases before the external call, so their observed
response count is below the number of seeds selecting that primary scenario.

Two background API calls rendezvous at their `InTx` boundaries. The seed selects
which whole transaction runs next; memstore cannot interleave operations inside a
transaction. Worker steps with fault injection remain serial, and store faults are
not injected during overlap waves. P3, P4, and the history-prefix part of P2 are
checked between scheduled transactions. All four properties and explicit outcomes
are checked for complete scenarios.

The campaign uses logical time, in-process engine reconstruction and an idempotency
ledger. It does not test arbitrary instruction preemption, real process death,
HTTP transport, or PostgreSQL crash recovery. The separate [PG campaign](lab-pg.md)
uses real clocks and network I/O with a narrower driver.

[Mutation testing](lab-mutation.md) caught 25 of 26 production mutants, with the
remaining mutant justified as equivalent for engine-reachable states. That evidence
supports these checks' ability to detect the documented bugs. Neither score nor a
zero-failure seed range proves that the unmodified engine has no defects.

Full console output: [archived delta-campaign.log](raw/historical/lab/delta-campaign.log). The memstore and CLI code remained
unchanged throughout this run. A PG-only successful-result assertion was added after
it started; that helper is not called by this driver. Final mutation and verification
runs compiled the complete final source tree.
