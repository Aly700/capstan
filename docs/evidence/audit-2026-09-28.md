## M003 equivalence assessment

`PollWorkflowTask` appends TaskStarted and stores that same ID in the task while
marking the run InFlight. External events then go to the inbox. Completing, failing,
expiring or closing the task removes/replaces it or clears the current-flight state.
The remaining token guards require the same current task and
`run.LastEventID == token.StartedEventID`. On engine-reachable states this implies
`task.StartedEventID == token.StartedEventID`, so M003 removes a redundant comparison.
The independent full 2,000-seed mutant run supports this argument; it does not replace
it. The argument excludes direct database corruption and multiple simultaneous mutants.
All other 25 mutants are caught, with every first failing seed matching the recorded table.
